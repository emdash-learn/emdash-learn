# Support

Use the appropriate channel:

- Reproducible defects:
  [GitHub Issues](https://github.com/emdash-learn/emdash-learn/issues/new/choose)
- Usage questions and design discussion:
  [GitHub Discussions](https://github.com/emdash-learn/emdash-learn/discussions)
- Security vulnerabilities:
  [private vulnerability reporting](https://github.com/emdash-learn/emdash-learn/security/advisories/new)

Include the EmDash Learn, EmDash, Node.js, and Astro versions plus a minimal
reproduction when requesting help. Community support is best-effort; no
response-time guarantee is provided for general questions.
