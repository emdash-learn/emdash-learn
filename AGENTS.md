This repo is an emdash plugin. The emdash framework lives in a **sibling repo** at `/Users/baezor/dev/emdash/`, linked into `lms-core/node_modules/emdash` via symlink to `emdash/packages/core`. ## Known issues (as of commit 1aa9e69, T28)

Tracked in `docs/emdash-issues-from-t28.md` — ready-to-file GitHub issue drafts for six regressions found while walking through the T28 local testing doc. Prioritized list:

1. **Blocker (emdash repo):** `usePluginPage` in `emdash/packages/admin/src/lib/plugin-context.tsx` does exact-string matching only. Plugin pages registered with `:param` keys (which lms-core T28 does for every dynamic route) are unreachable — the router falls back to `SandboxedPluginPage` and 404s. Every admin CRUD page in T28 is blocked. Proposed patch in the notes file.
2. **Demo deps/config (this repo):** `demos/simple` is missing `@lingui/babel-plugin-lingui-macro` devDep, `lingui.config.js`, and Vite `server.fs.allow` entries for the sibling emdash repo. All three need to land together for a fresh clone to boot the dev server.
3. **Doc nits (this repo):** `docs/testing-t28-local.md` §3 has the wrong dev-bypass URL; §A.6 describes a "Students" sidebar nav that doesn't exist (the actual path is Courses → course detail → Progress tab → student row).

Until #1 lands in emdash, admin UI testing (§A.1–A.6) is blocked. §B (student site), §C (direct RPC via curl), and §D (i18n/RTL) of the testing doc are still reachable and worth running.

## Conventions

- Plugin definition: `src/index.ts` (descriptor) + `src/sandbox-entry.ts` (runtime) + `src/admin.tsx` (React pages registry) + `src/astro/` (site-side blocks). See `src/index.ts` comment block for the split.
- Admin pages are registered in `src/admin.tsx` as a `Record<string, ComponentType>`. Components self-parse params from `window.location.pathname` (e.g. `parseCourseIdFromPath` in `CoursePage.tsx:89`).
- Route names on the plugin's RPC surface use `namespace:action` form (e.g. `instructor:course-overview`, `admin:analytics-overview`). Exposed via the `routes` block in `sandbox-entry.ts`.
